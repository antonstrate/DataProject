# DataProject

## Files

- `task2_model.py` — `IncomeModel` and `gini`: The IncomeModel used in Task 2.
  Gini is a function used to calculate the Gini Coefficient in Task 2.

- `Results.ipynb` — the single self-contained notebook with all results,
  figures and answers.

## Running

Open `Results.ipynb` in the same folder as `task2_model.py`
and run all cells from the top ("Restart Kernel and Run All"). No other setup
is required beyond `numpy`, `scipy`, `pandas` and `matplotlib`.
